🔄 Limpiar Sesión y Re-Login

¿Por qué necesitas hacer esto?

Cuando los roles de un usuario se actualizan en Firebase, el token JWT actual no incluye esos cambios. Necesitas cerrar sesión y volver a iniciar para obtener un nuevo token con los roles actualizados.

Proceso Automático:

  • Cierra sesión de Firebase Auth
  • Limpia localStorage y sessionStorage
  • Limpia cookies relacionadas
  • Limpia la consola del navegador
  • Redirige al login automáticamente

Después de hacer re-login:

  • El nuevo token incluirá el rol super_admin
  • Podrás asignar roles a otros usuarios
  • El error 403 desaparecerá
