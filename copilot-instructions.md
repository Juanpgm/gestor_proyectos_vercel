# Instrucciones para GitHub Copilot

- Usa siempre TypeScript en lugar de JavaScript.
- Prefiere programación funcional cuando sea posible.
- Sigue la guía de estilos ESLint de este proyecto.
- Usa nombres de variables descriptivos en inglés.
- Para tests, siempre genera ejemplos con Jest.
- Intenta mantener el cógido eficiente
- Elimina lo que no funcione sin dañar lo que si funcione.
