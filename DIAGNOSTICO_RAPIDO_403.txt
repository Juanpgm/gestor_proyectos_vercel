## 🔍 DIAGNÓSTICO RÁPIDO - ERROR 403

Abre la **consola del navegador** (presiona F12) y pega este código:

```javascript
// Verificar roles del usuario actual
console.log('='.repeat(60));
console.log('🔍 DIAGNÓSTICO DE PERMISOS');
console.log('='.repeat(60));
console.log('');

const session = JSON.parse(localStorage.getItem('auth_session'));

if (!session || !session.user) {
  console.log('❌ No hay sesión activa');
} else {
  const user = session.user;
  
  console.log('📋 Usuario actual:');
  console.log('- Email:', user.email);
  console.log('- UID:', user.uid);
  console.log('- Roles:', user.roles);
  console.log('');
  
  const hasSuperAdmin = user.roles?.includes('super_admin');
  
  if (hasSuperAdmin) {
    console.log('✅ Usuario tiene rol super_admin');
    console.log('');
    console.log('El usuario DEBERÍA poder asignar roles.');
    console.log('Si aún ves error 403:');
    console.log('1. Cierra sesión y vuelve a iniciar');
    console.log('2. Verifica que el token se esté renovando');
  } else {
    console.log('❌ Usuario NO tiene rol super_admin');
    console.log('');
    console.log('🚨 ESTE ES EL PROBLEMA');
    console.log('');
    console.log('✅ SOLUCIÓN:');
    console.log('1. Ir a Firebase Console:');
    console.log('   https://console.firebase.google.com/');
    console.log('2. Proyecto: unidad-cumplimiento-aa245');
    console.log('3. Firestore Database → usuarios');
    console.log('4. Buscar documento con UID:', user.uid);
    console.log('5. Editar campo "roles"');
    console.log('6. Agregar: "super_admin"');
    console.log('7. Guardar');
    console.log('8. Cerrar sesión y volver a iniciar en la app');
  }
}

console.log('');
console.log('='.repeat(60));
```

Copia el código de arriba y pégalo en la consola del navegador.
